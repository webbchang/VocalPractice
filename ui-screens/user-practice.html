音高偏差說明 (Pitch Deviation)

音高偏差以 cent 為單位。100 cent = 1 半音 (semitone)。例如： C4 到 C#4 之間的距雌是 100 cent。

  • 0 cent = 完美音準（你的音準跟參考音符完全一致）
  • 正值 (例: +20) = 你的音高too 高（sharp）
  • 負值 (例: -15) = 你的音高too 低（flat）
  • ±50 cent 以下 = 非常接近，聽起來幾乎無差異
  • ±100 cent = 你唱到了鄰近的半音（一個不同的音符）

分數計算：pitchScore = max(0, 100 - |平均音高偏差| * 0.5)，權重 70%。
